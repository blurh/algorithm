# 树 (Tree)

## 基本概念

### 术语定义
1. **节点 (Node)**: 包含一个数据元素及若干指向子树分支的信息
2. **节点的度 (Degree)**: 一个节点拥有子树的数目
3. **叶子节点 (Leaf)**: 度为 0 的节点，也称终端节点
4. **分支节点 (Branch)**: 度不为 0 的节点，也称非终端节点
5. **树的度**: 树中所有节点度的最大值
6. **节点的层次 (Level)**: 从根节点开始，根为第 1 层，子节点在父节点层次 +1
7. **树的深度/高度 (Depth/Height)**: 树中所有节点层次的最大值
8. **有序树**: 子树有先后次序的树
9. **无序树**: 子树无先后次序的树
10. **森林 (Forest)**: 由 m (m ≥ 0) 棵互不相交的树构成
11. **前驱节点**: 中序遍历中，当前节点的前一个节点
12. **后继节点**: 中序遍历中，当前节点的后一个节点

### 旋转技巧
**口诀**: 左旋拎右左挂右，右旋拎左右挂左

```
左旋:              右旋:
   x                 y
    \               /
     y      →      x
    /               \
   T              T
```

## 二叉树 (Binary Tree)

### 基本定义
- **特性**: 每个节点最多只有两个子节点，且有左右之分
- **类型**:
  - 满二叉树: 每层节点都达到最大数量
  - 完全二叉树: 除最后一层外都是满的，最后一层从左到右连续
  - 平衡二叉树: 左右子树高度差不超过 1

### 遍历方式
- **前序遍历 (Pre-order)**: 根 → 左 → 右
- **中序遍历 (In-order)**: 左 → 根 → 右
- **后序遍历 (Post-order)**: 左 → 右 → 根
- **层序遍历 (Level-order)**: 逐层从左到右 (BFS)
- **深度优先搜索 (DFS)**: 前/中/后序遍历

### 性质
- 第 i 层最多有 2^(i-1) 个节点
- 深度为 k 的二叉树最多有 2^k - 1 个节点
- n₀ = n₂ + 1 (叶子节点数 = 度为2的节点数 + 1)

## 二叉搜索树 (Binary Search Tree, BST)

### 定义
- **特性**: 
  - 左子树所有节点值 < 根节点值
  - 右子树所有节点值 > 根节点值
  - 左右子树也都是二叉搜索树

### 性能
- **时间复杂度**:
  - 平均: O(log n)
  - 最差: O(n) - 退化成链表
- **中序遍历**: 得到有序序列

### 缺点
- 插入顺序影响树的形态
- 可能退化成单链表

## AVL 树 (平衡二叉搜索树)

### 发明
- **发明人**: Adelson-Velsky 和 Landis (1962)
- **名称来源**: 两位发明人姓氏首字母

### 定义
- **特性**: 任何节点的左右子树高度差不超过 1 的二叉搜索树

### 平衡维护
- **四种旋转**:
  - LL (左左): 右旋
  - RR (右右): 左旋
  - LR (左右): 先左旋后右旋
  - RL (右左): 先右旋后左旋

### 性能
- **时间复杂度**: O(log n) - 查找、插入、删除
- **空间复杂度**: O(n)
- **平衡因子**: 每个节点需存储高度信息

### 优势
- 严格平衡，查找效率高
- 最坏情况下性能也稳定

### 劣势
- 插入删除需要频繁旋转，维护成本高

## 红黑树 (Red-Black Tree)

### 定义
具有以下 5 个性质的平衡二叉搜索树:
1. 每个节点要么是红色，要么是黑色
2. **根节点是黑色**
3. **每个叶子节点 (NIL) 是黑色**
4. **红色节点的两个子节点都是黑色** (不能有两个连续的红节点)
5. **从任一节点到其叶子节点的所有路径包含相同数目的黑节点** (黑高 black-height)

### 注意
- 叶子节点指的是黑色的 NIL 节点
- NIL 节点主要用于边界判断

### 平衡维护
- **变色**: 改变节点颜色
- **旋转**: 左旋、右旋
- **组合策略**: 根据插入/删除情况选择变色或旋转

### 性能
- **时间复杂度**: O(log n) - 查找、插入、删除
- **空间复杂度**: O(n)

### AVL vs 红黑树
- **AVL**: 严格平衡，查找更快，但插入删除成本高
- **红黑树**: 近似平衡，插入删除更快，查找略慢
- **应用**: 
  - C++ STL map/set: 红黑树
  - Java TreeMap/TreeSet: 红黑树
  - Linux CFS 调度器: 红黑树

### 变种
- **左倾红黑树 (LLRB)**: 
  - 由 2-3 树演化而来
  - 约束：红节点只能是左子节点
  - 实现更简单

## B 树 (B-Tree)

### 定义
- **特性**: 一种多路平衡查找树，适合外存储器（磁盘）访问

### 基本性质
1. **阶的定义**: B 树的阶 m 表示节点最多有 m 个子节点
2. **根节点**: 关键字数量 1 ≤ k ≤ m-1
3. **非根节点**: 关键字数量 ⌈m/2⌉ ≤ k ≤ m-1
4. **节点内关键字**: 从小到大排列，左子树 < 关键字 < 右子树
5. **所有叶子节点**: 在同一层（完全平衡）
6. **非叶子节点**: 有 k 个关键字就有 k+1 个子节点
7. **子节点数量**: 非叶子节点至少有 ⌈m/2⌉ 个子节点
8. 当 m = 2 时，即为二叉树

### 性能
- **时间复杂度**: O(log n)
- **磁盘 I/O**: O(logₘ n) - m 为树的阶

### B+ 树
- **改进**: 
  - 所有数据存储在叶子节点
  - 叶子节点通过链表连接
  - 非叶子节点仅存储索引
- **优势**:
  - 范围查询效率高
  - 扫描更高效
- **应用**: 
  - MySQL InnoDB 索引 (341 阶)
  - MongoDB WiredTiger 存储引擎

### B 树 vs B+ 树
| 特性 | B 树 | B+ 树 |
|------|------|-------|
| 数据存储 | 所有节点 | 仅叶子节点 |
| 叶子链表 | 无 | 有 |
| 范围查询 | 较慢 | 快 |
| 磁盘 I/O | 较多 | 较少 |

## Treap (树堆)

### 定义
- **特性**: 
  - 按 key 构成二叉搜索树 (BST)
  - 按 priority (优先级) 构成最小堆 (Min Heap)
- **名称来源**: Tree + Heap

### 实现方式
- **旋转 Treap**: 使用旋转维护平衡
- **非旋转 Treap**: 使用 split 和 merge 维护平衡

### 特点
- **随机化**: priority 随机生成，期望高度 O(log n)
- **简单**: 比 AVL 和红黑树实现简单
- **限制**: 旋转 Treap 对区间操作和持久化支持不足

### 性能
- **时间复杂度**: O(log n) - 期望

## Trie (字典树 / 前缀树)

### 定义
- **特性**: 将字符串的公共前缀合并，形成树状结构

### 性能
- **构建**: O(n) - n 为所有字符串总长度
- **查询**: O(k) - k 为查询字符串长度
- **空间复杂度**: O(n × σ) - σ 为字符集大小

### 应用场景
- 目录结构
- 字符串检索
- 前缀匹配
- 词频统计
- 字符串排序
- 搜索引擎自动补全
- 敏感词过滤
- IP 路由表 (最长前缀匹配)

### 优化
- **压缩 Trie (Radix Tree)**: 合并单子节点链
- **Double-Array Trie**: 使用两个数组实现，节省空间

## 树结构对比

| 树类型 | 平衡性 | 查找 | 插入 | 删除 | 特点 | 应用 |
|--------|--------|------|------|------|------|------|
| BST | 不保证 | O(n) | O(n) | O(n) | 简单 | 基础 |
| AVL | 严格平衡 | O(log n) | O(log n) | O(log n) | 查找快 | 查询密集 |
| 红黑树 | 近似平衡 | O(log n) | O(log n) | O(log n) | 插删快 | STL, Java |
| B树 | 完全平衡 | O(log n) | O(log n) | O(log n) | 多路 | 数据库 |
| Treap | 期望平衡 | O(log n) | O(log n) | O(log n) | 简单 | 竞赛 |
| Trie | - | O(k) | O(k) | O(k) | 前缀 | 字符串 |

**说明**: k 为字符串长度，n 为节点数量
