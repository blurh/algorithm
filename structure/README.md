# 数据结构

## 线性数据结构

### 链表 (Linked List)
- **定义**: 数据元素的逻辑顺序通过指针链接，物理存储单元非连续、非顺序
- **类型**:
  - 单链表: 每个节点只有一个后继指针
  - 双向链表: 每个节点有前驱和后继两个指针
  - 循环链表: 尾节点指向头节点
- **时间复杂度**:
  - 查找: O(n)
  - 插入/删除: O(1) - 在指定位置
- **优势**: 插入删除灵活，不需要连续内存
- **劣势**: 随机访问慢，需要额外的指针空间

---

### 栈 (Stack)
- **定义**: 限定仅在栈顶进行插入和删除操作的线性表
- **特性**: LIFO (Last In First Out) - 后进先出
- **基本操作**:
  - Push: 入栈 - O(1)
  - Pop: 出栈 - O(1)
  - Peek: 查看栈顶 - O(1)
- **应用场景**:
  - 函数调用栈
  - 表达式求值
  - 括号匹配
  - 深度优先搜索 (DFS)
  - 浏览器前进后退

---

### 队列 (Queue)
- **定义**: 只允许在一端插入、另一端删除的线性表
- **特性**: FIFO (First In First Out) - 先进先出
- **类型**:
  - 普通队列: 单向队列
  - 双端队列 (Deque): 两端都可插入删除
  - 优先队列: 按优先级出队，通常用堆实现
  - 循环队列: 首尾相连，避免空间浪费
- **基本操作**:
  - Enqueue: 入队 - O(1)
  - Dequeue: 出队 - O(1)
- **应用场景**:
  - 消息队列
  - 广度优先搜索 (BFS)
  - 任务调度
  - 缓冲区管理

---

## 树形数据结构

### 树 (Tree)
- **定义**: 用来模拟具有树状结构性质的数据集合
- **基本术语**:
  - 节点: 包含数据元素及指向子树的分支信息
  - 度: 节点拥有的子树数目
  - 叶子节点: 度为 0 的节点
  - 分支节点: 度不为 0 的节点
  - 树的度: 所有节点度的最大值
  - 深度/高度: 所有节点层次的最大值
  - 森林: 由 m (m ≥ 0) 棵互不相交的树组成
- **遍历方式**:
  - 前序遍历: 根 → 左 → 右
  - 中序遍历: 左 → 根 → 右
  - 后序遍历: 左 → 右 → 根
  - 层序遍历: 逐层从左到右
- **详见**: `structure/tree/` 目录

---

### 堆 (Heap)
- **定义**: 用数组实现的完全二叉树，根据"堆属性"决定节点位置
- **类型**:
  - 最大堆: 父节点 ≥ 子节点
  - 最小堆: 父节点 ≤ 子节点
- **时间复杂度**:
  - 插入: O(log n)
  - 删除最值: O(log n)
  - 查找最值: O(1)
  - 建堆: O(n)
- **应用场景**:
  - 优先队列
  - 堆排序
  - Top K 问题
  - 中位数维护
- **详见**: `structure/heap/` 目录

## 散列数据结构

### HashMap (哈希表)
- **定义**: 通过哈希函数将 key 转换为数组下标，实现快速的键值对存储和查询
- **原理**: 
  1. 计算 key 的哈希值
  2. 映射到数组索引
  3. 处理哈希冲突（链表法或开放寻址法）
- **时间复杂度**:
  - 无冲突: O(1)
  - 有冲突: O(n) - 最坏情况
  - 平均: O(1)
- **冲突解决**:
  - 链表法 (拉链法): 同一位置用链表存储
  - 开放寻址法: 探测下一个空位
  - 再哈希法: 使用多个哈希函数
- **负载因子**: 元素数量 / 数组长度，通常超过 0.75 时扩容
- **应用**: 缓存、去重、统计频次、快速查找

---

### Set (集合)
- **定义**: 不允许重复元素的数据结构
- **实现方式**:
  - 基于 HashMap: 只使用 key
  - 基于平衡树: 有序集合
  - 位图 (BitSet): 整数集合
- **基本操作**:
  - 添加: O(1) 或 O(log n)
  - 删除: O(1) 或 O(log n)
  - 查找: O(1) 或 O(log n)
  - 交集、并集、差集
- **应用**: 去重、集合运算、会员判断

---

### TreeMap (有序映射)
- **定义**: 基于平衡树（如红黑树）实现的有序键值对存储
- **特性**: 
  - 键按顺序排列
  - 支持范围查询
- **时间复杂度**:
  - 增删改查: O(log n)
  - 范围查询: O(log n + k) - k 为结果数量
- **对比 HashMap**:
  - TreeMap: 有序、O(log n)
  - HashMap: 无序、O(1)
- **应用**: 需要有序遍历、范围查询的场景

## 数据结构选择指南

| 需求 | 推荐数据结构 | 原因 |
|------|-------------|------|
| 快速查找 | HashMap, HashSet | O(1) 平均时间复杂度 |
| 有序数据 | TreeMap, 平衡树 | 维护有序性 |
| 频繁插入删除 | 链表 | O(1) 插入删除 |
| 随机访问 | 数组 | O(1) 索引访问 |
| LIFO 操作 | 栈 | 后进先出 |
| FIFO 操作 | 队列 | 先进先出 |
| Top K 问题 | 堆 | O(log n) 维护最值 |
| 前缀匹配 | Trie 树 | 高效字符串前缀查询 |
| 范围查询 | B 树, 线段树 | 高效区间操作 |
| 层次关系 | 树 | 天然层次结构 |
