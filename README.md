# Algorithm

一个用 Go 语言实现的算法与数据结构学习项目。

## 内容

- **排序算法** (`sort/`) - 冒泡、快排、归并、堆排序等 10 种排序算法
- **查找算法** (`search/`) - 二分、插值、斐波那契等 5 种查找算法
- **哈希算法** (`hashing/`) - BKDR、DJB、MurMur、CRC32 等 18 种哈希函数
- **数据结构** (`structure/`) - 链表、栈、队列、哈希表、各种树(AVL、红黑树、B树等)
- **字符串匹配** (`strings/`) - 朴素匹配、RK 算法

## 使用

```bash
go test ./...
```
